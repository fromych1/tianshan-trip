# 🏔️ Tian Shan & Issyk-Kul Road Trip Planner (14 дней)
### Интерактивная карта-планировщик автомобильного путешествия: Казахстан — Кыргызстан

> **Маршрут:** Караганда ➔ Балхаш ➔ Алматы ➔ Чарынский каньон ➔ Кольсай и Каинды ➔ КПП Каркыра ➔ Северный Иссык-Куль ➔ Каракол ➔ Джети-Огуз и Барскоон ➔ Каньон Сказка ➔ Южный Иссык-Куль (Боконбаево) ➔ Башня Бурана ➔ Бишкек (Ала-Арча) ➔ КПП Кордай ➔ Балхаш ➔ Караганда.
>
> **Общий километраж:** ~3 340 км  
> **Продолжительность:** 14 дней  
> **Формат:** Путешествие на своём авто (комфортно для кроссовера / внедорожника)

---

## 🌟 Ключевые возможности планировщика

1. **Интерактивная карта Тянь-Шаня (Leaflet + CartoDB/OSM):**
   - Каждый день закодирован собственным ярким цветом.
   - Подробные остановки, смотровые площадки, природные парки и координаты ночлегов.
   - Быстрый фильтр по дням с автозумом и подсветкой активного участка пути.
2. **Совместная работа с друзьями (Community Layer):**
   - Друзья могут кликнуть в любую точку карты или нажать **«+ Добавить точку»**.
   - Возможность указать автора, категорию (еда, смотровая, ночлег, совет) и комментарий.
   - Система голосования **«👍 Хочу сюда!»** с автоматической сортировкой лучших мест.
   - Двусторонняя синхронизация: данные сохраняются локально (localStorage) и на сервере (community_points.json).
3. **Навигация в 1 клик:**
   - Каждая точка маршрута и рекомендация друзей содержит прямую ссылку на построение маршрута в **Google Карты**.
   - Кнопка **«📥 Скачать GPX»** генерирует валидный файл со всеми треками и путевыми точками для оффлайн-навигаторов: **Organic Maps**, **OsmAnd**, **2ГИС**, **Garmin**.
4. **Памятка водителю:**
   - Требования к прохождению границ (**КПП Каркыра** и **КПП Кордай**).
   - Обязательная автостраховка в Кыргызстане, ПДД, связь/SIM-карты (О!, Beeline KG, Mega) и обмен валюты (KGS).

## 🚀 Быстрый запуск на компьютере

### Способ 1 (Windows — в 1 клик):
Дважды кликните по файлу:
`	ext
start_trip_planner.bat
`
Скрипт автоматически запустит локальный сервер на порту 5050 и откроет страницу в вашем браузере.

### Способ 2 (через терминал):
`ash
python server.py
`
Откройте в браузере: http://localhost:5050

## 📱 Как подключить друзей к планировщику

### Вариант 1: В одной Wi-Fi сети (дома или в гостях)
Когда сервер запущен на вашем ноутбуке, он показывает адрес в локальной сети (например, http://192.168.1.45:5050). Друзья со своих смартфонов просто переходят по этому адресу, смотрят маршрут и добавляют свои метки.

### Вариант 2: Бесплатная публикация в интернет (GitHub Pages + Firebase)
Чтобы любой друг из Казахстана и России мог открыть ссылку без VPN, видеть карту и добавлять свои точки в общую базу в реальном времени:

#### Шаг 1. Бесплатная база данных Firebase (2 минуты):
1. Откройте [Firebase Console](https://console.firebase.google.com/) и войдите под своим Google-аккаунтом.
2. Нажмите **«Создать проект»** (например, `tianshan-roadtrip`).
3. В левом меню выберите **Build ➔ Realtime Database** ➔ нажмите **«Создать базу данных»** (выберите локацию `Belgium (europe-west1)`).
4. Во вкладке **Правила (Rules)** установите открытый доступ на чтение/запись:
   ```json
   {
     "rules": {
       ".read": true,
       ".write": true
     }
   }
   ```
5. В настройках проекта (⚙️ ➔ Настройки проекта) прокрутите вниз до раздела «Ваши приложения», выберите **Веб (</>)** и скопируйте объект `firebaseConfig` в файл `firebase_config.js`.

#### Шаг 2. Публикация на GitHub Pages (1 минута):
1. Создайте репозиторий на GitHub и загрузите файлы проекта.
2. В репозитории перейдите в **Settings ➔ Pages ➔ Build and deployment ➔ Branch: `main` (или `master`) ➔ папка `/ (root)` ➔ Save**.
3. Через минуту появится ссылка: `https://ваш-логин.github.io/имя-репозитория/`.
4. Отправьте эту ссылку друзьям в чат WhatsApp/Telegram — теперь любые добавленные точки и лайки мгновенно отображаются у всех в реальном времени!
